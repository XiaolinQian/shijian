# 宣传图生成记录

本次尝试使用内置 `image_gen`（imagegen 技能默认路径），没有使用 OpenAI API 或 CLI 回退。工具多次返回空结果，也没有返回可保存的图片路径，因此未把任何 AI 生图标记为交付成功。

最终交付采用真实应用截图、既有应用图标与本地可编辑排版（Pillow），输出 4 张 1080 × 1920 PNG、网站缩略图和横版分享封面。源文件为 `render_press.py`。

## 最后尝试的提示词

> Create and return a finished promotional poster image for the Chinese desktop productivity app 日序 · TodoApp. Portrait 9:16, 1080×1920. Premium editorial design with a dark forest-green background, warm ivory Chinese typography, mint accent and beautifully lit 3D paper checklist, bell, and report sheets in the middle. Typography must be big and readable, exactly these Chinese words: top small brand “日序 · TodoApp”; main headline “把注意力，留给重要的事。”; supporting line “记录待办 · 每日提醒 · 自动复盘”; three small feature chips “日报” “周报” “月报”; bottom caption “本地优先 · 无需账户”. Generous negative space and safe margins: keep all text away from the rightmost 140 pixels and bottom 220 pixels for short-video platform controls. No people, no fake UI screenshots, no QR code, no unrequested text, no watermark. Finished marketing poster, sophisticated restrained composition, no purple gradients, no clutter.
