# 宣传站验收

- Chromium 真实浏览器验证通过：1440、1024、768、390、320 像素宽度，无横向溢出，所有图片加载正常。
- 页面资源、下载地址和站内锚点全部有效；没有外部字体或脚本请求。
- 实际点击下载 DMG、素材 ZIP 和宣传 PNG，下载文件 SHA-256 与源文件相同。

- 直接以 file:// 打开首页、加载本地图片通过。

- ZIP CRC 检查通过，部署 ZIP 中 HTML/CSS 与当前源文件一致。
